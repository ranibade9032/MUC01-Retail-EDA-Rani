💜 Retail Product Performance EDA

Exploratory Data Analysis of Retail Sales using Python

📌 About the Project

This project analyzes retail sales data to understand product performance, category revenue, discount patterns, and weekday sales trends.

The goal is to identify useful business insights from retail transaction data using data analysis techniques.

📈 Key Findings

  • Electronics revenue declined from January to June.
  • Apparel revenue increased during the same period.
  • Average revenue per transaction generally decreased as discounts increased.

🎯 Project Objective

To use data analysis to discover sales patterns and help businesses better understand product and category performance.
