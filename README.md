# Retail Product Performance EDA

## Project Overview
This project analyses retail sales data to understand category performance, product revenue, discount effectiveness, and sales patterns.

## Objectives
- Analyse monthly revenue by product category.
- Identify top- and bottom-performing products.
- Study sales patterns by day of the week.
- Evaluate the relationship between discounts and average revenue per transaction.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings
- Electronics revenue declined from January to June 2026.
- Apparel revenue increased during the same period.
- Average revenue per transaction generally decreased as discount levels increased.
- Saturday was the best-performing weekday, while Monday was the weakest.

## Files Included
- `MUC01_Retail_Sales_EDA.ipynb` — Analysis and charts
- `MUC01_Retail_Sales_Dataset.csv` — Dataset

## Conclusion
The analysis helps identify sales trends and supports better retail business decisions. Further analysis using profit margins and stock availability data would improve recommendations.
